# Code of Conduct

Be respectful in ZenPTT issues and discussions. Discuss the project and its
behavior, not the people involved. Harassment, threats, discrimination, personal
attacks, spam, and publication of someone else's private information are not
allowed.

These rules apply to interactions in this repository. The maintainer may hide
comments, lock discussions, or restrict participation when these rules are
violated. Use GitHub's **Report content** feature to report abuse to GitHub.

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
