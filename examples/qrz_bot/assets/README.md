# QRZ reference audio

Status: current

Purpose: record reference-audio generation, pinned bytes, and runtime format.

Audience: bot developers and asset maintainers.

Authority: this file owns generation, the pinned hash, and preparation details for the
reference QRZ audio asset.

Code anchors: `examples/qrz_bot/generate_audio.py`, `examples/qrz_bot/qrz_bot.py`,
and `zenptt_headless.load_pcm`.

Update when: the generator, asset bytes, PCM format, preparation, or runtime loading
changes.

The PCM file is a developer-example asset. It is excluded from the production
headless image and four-file server delivery. The example Compose file mounts
`QRZ.pcm` read-only at `/audio/QRZ.pcm`; the bot loads it once into immutable PCM
shared by all responses.

| File | Format | Size | SHA-256 |
|---|---|---:|---|
| `QRZ.pcm` | 16 kHz mono signed 16-bit little-endian PCM | 88,800 bytes | `974dcf2024c7ca7e8609e428c4dd0aa7c2ecf73c9ae9aa5ef9aa481c370f287c` |

The audio is generated by [`generate_audio.py`](../generate_audio.py) from the Morse
sequence `--.- .-. --..` (QRZ). It uses a 700 Hz sine tone, 75 ms dot units, and
5 ms fades at each tone boundary. It does not incorporate an external recording.
Regenerate the checked-in file from the repository root with:

```console
python examples/qrz_bot/generate_audio.py
```

The result contains 44,400 samples (2.775 seconds). The normal sender pads the
final frame to 139 Opus frames (2.78 seconds) and uses a fresh encoder for each
response. The asset test checks that the file matches the generator and pinned hash.

For a different sound, copy the example, prepare a local PCM file offline, and
mount it read-only at `/audio/QRZ.pcm` in the copied Compose file. Do not add the
reference asset to the production image or server delivery.
The example runtime uses the public `load_pcm()` API.
