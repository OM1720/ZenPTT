# Security policy

## Supported versions

Reports affecting the current default branch or the latest server-hosted APK are
accepted. Older versions have no fixed support period.

## Report a vulnerability

Use **Report a vulnerability** on this repository's GitHub Advisories page. Do not
disclose vulnerabilities in public issues or pull requests.

Include the affected component and version, the impact, and steps to reproduce.
Do not include passwords, signing keys, channel codes, conversation audio, or
private diagnostic reports.
