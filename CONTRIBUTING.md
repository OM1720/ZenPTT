# Contributing to ZenPTT

ZenPTT accepts reproducible bug reports through the
[GitHub Bug report form](https://github.com/OM1720/ZenPTT/issues/new?template=bug_report.yml).
External pull requests are not reviewed. There is no guaranteed response or fix
time for an issue.

Before reporting a bug, check the [known limitations](docs/KNOWN_LIMITATIONS.md)
and existing issues. Include the affected component, version or commit, device
and operating system or browser, steps to reproduce, and what you expected and
observed. The form does not ask for an email address; GitHub shows the reporting
account's public username.

Issues are public. Do not include passwords, signing keys, channel codes,
conversation audio, private diagnostic reports, raw logs, or server addresses.
If diagnostics help explain a bug, share only the relevant, redacted details.
See the [support guide](docs/SUPPORT.md) for the data diagnostics may contain.

Report security vulnerabilities privately through
[GitHub Advisories](https://github.com/OM1720/ZenPTT/security/advisories), as
described in the [security policy](SECURITY.md). Do not open a public issue for a
vulnerability.
